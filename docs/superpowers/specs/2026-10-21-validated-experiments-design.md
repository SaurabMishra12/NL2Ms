# Validated experiment suite v2

User-authorized scope: implement the audit's proposed experiments as Kaggle GPU and local CPU notebooks, genuine model/dataset loading, real tests, restart-safe raw records, and automatic stopping before 11 hours of notebook execution. Original evidence stays immutable.

Design decisions: add an isolated `nl2ms/v2` runner rather than silently rerun the invalid legacy pipeline. Reuse audited pure numerical functions and model architecture discovery. Main benchmark uses GSM8K, TruthfulQA, WinoGrande and ARC-Challenge (150 each); copied-answer controls are explicitly derived from these records and never called benchmark examples. Qwen2.5-7B-Instruct is primary; Mistral-7B-Instruct-v0.3 is a separately scheduled replication. Pin resolved model/dataset commits per scientific run. All long runs are gated by finite logits/hidden states, final norm/head reconstruction, attention normalization, batch consistency, generation health and no-op intervention checks. Fail closed; no synthetic fallback and no silent quantization changes.

A run consists of independently committed generation, extraction and perturbation units. Checksum indexes permit mounted read-only previous Kaggle outputs; a new session writes only new units. Changes to scientific config/source/model/dataset identity cannot silently reuse units. Atomic directory rename is the commit boundary. Preserve failed/nonfinite raw arrays rather than sanitize them. Deadline/reserve/disk exits are incomplete states, not completed experiments.

Kaggle notebook embeds a checksummed source archive so no unpublished GitHub commit is needed. First code cell starts the session clock; dependency setup and worker subprocesses are bounded by that clock. Stop admitting expensive work at 10h40m, TERM worker before 10h55m, KILL before 11h. OS/CUDA uninterruptible hangs cannot be guaranteed away. Parent notebook monitors process rather than relying on Python callbacks interrupting CUDA.

Capture policy is explicit: default full attention matrices and full hidden/residual streams for the analyzed sequence, full-vocabulary float32 logits at each layer for selected prompt/answer/temporal positions, output logits and selected top-k/entropy for every generated token. `full_logits_all_positions` is optional and may fill a session quickly. Store natural arrays without lossy quantization. Bound sequence/context length explicitly; reject overlong prompts, never silently truncate. Disk checks stop before reserve; raw outputs can exceed Kaggle disk across the full suite, so resume across sessions rather than discard evidence.

Stages: diagnostic configuration comparisons; gated main generation/extraction; copied-answer nonreasoning controls; stratified correct/incorrect sensitivity cohorts; independent-detector and boundary controls; J-space directional probes; paired critical/nearby/random/depth controls with common perturbation seeds and magnitude, actual final-answer decoding and correctly typed proxy; precision/seeds and second-model replications; local geometry, nulls, confounds, paired statistics, multiple comparison control and reports. Freeze primary metric definition in config; findings exploratory until a separate confirmatory cohort.

No hardware promise: Kaggle currently documents T4 x2, not T5 x2. Detect available GPUs. A local tiny/random model validates plumbing only; an actual pretrained CPU smoke and actual benchmark download are separate tests. Real Kaggle 7B dual-GPU validation must happen in notebook preflight and is not claimed from CPU tests.
